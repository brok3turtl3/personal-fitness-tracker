## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| edit form input → service | Edited values are untrusted; the service re-validates (05-03) before write |
| edit-mode UI state → entry on disk | The original entry must stay untouched until Save commits |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06-01 | Tampering | edit Save path | mitigate | Save calls the 05-03 service update which validate-first + preserves id/createdAt; component delegates business logic (CLAUDE.md Component Pattern) |
| T-05-06-02 | Repudiation | Discard changes | mitigate | Discard writes nothing; the original entry is untouched on disk until Save — spec asserts no service write on Discard |
| T-05-06-03 | Information Disclosure | a11y color-only signalling | mitigate | Edit mode signalled by `Editing entry` header + copy + role=status announce, not color (UI-SPEC); axe color-contrast now enforced |
| T-05-06-04 | Tampering | readings type dispatch | mitigate | editingType drives the correct typed update method — a BP edit can never call the ketone update (spec per type) |
