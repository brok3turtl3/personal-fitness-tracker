<objective>
Build the six read-only `query_*` data tools (CHAT-02) as a single `DataQueryToolExecutor` wrapping the existing domain services with bounded/summarized output (D-14), and wire them into `ToolRegistryService` alongside the memory executor, adding the `isWriteProposal(name)` predicate the agentic loop needs.

Purpose: This is the data-read surface the live agentic loop fetches the user's actual logs through. Read-only ⇒ auto-execute (D-02). Bounding protects the token budget — a 5-year query must never dump the whole dataset (E6/Pitfall 6). Read-only safety (no `saveData`) is the E5 critical assertion. The `isWriteProposal` split lets the loop auto-execute queries while deferring memory/profile writes to the pending pill (D-03).

Output: `data-query-tool-executor.ts` + spec; `tool-registry.service.ts` extended + spec.
</objective>
