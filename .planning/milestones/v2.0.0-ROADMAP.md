## Milestone Summary

**Schema evolution:** V4→V5 (AI: memoryFiles, userProfile, aiToolSettings, ChatMessage.blocks) → V5→V6 (chat-block citation/server-tool shape) → V6→V7 (diet: densityGramsPerMl, widened units, DailyTargets). All additive, all backup-before-migrate with typed legacy interfaces.

**Key Decisions:**

- No clinical disclaimers on AI output — source attribution + per-claim confidence labels (strong | moderate | weak | animal-only | anecdotal | speculative) instead.
- Free-generated citations never render as links — only API-structured citations (`web_search_result_location`, `search_result`) become hyperlinks (bounds 14–95% LLM citation-fabrication risk).
- Anthropic-native tool use, not RAG/embeddings — bounded structured data for a single user.
- Memory via the official `memory_20250818` tool over `AppData.memoryFiles` with `/memories` path validation; `UserProfile` kept separate (structured, user-edited).
- LocalStorage stays — no IndexedDB; quota detection + lazy chat archival is the relief valve.
- D-17 SDK-boundary chokepoint — `anthropic-api.service.ts` is the sole `@anthropic-ai/sdk` importer; models/parsers stay SDK-agnostic via local structural types.
- Slim byte-stable cacheable system prompt (`cache_control: ephemeral`) + real `messages.countTokens` drive the rolling window; full per-domain detail arrives via `query_*` tools.

**Issues Resolved:**

- Diet logging friction (new-food entry, unit handling, daily display) — the milestone's primary motivation.
- Chart-vs-report day-grouping drift — single shared `groupByDay`/`toDateKey`; DST-correct local-day bucketing.
- 5× duplicated UUID generators + 6× duplicated chart-grouping helpers — collapsed to shared utilities.
- Silent storage failures / `as any` migration reads — typed migrate chain + backup-before-migrate + recovery banner.
- CRUD gap (no update for cardio/weight/readings) — full edit parity with id/createdAt preservation.

**Issues Deferred (carried to next milestone as known debt):**

- Phase 4 visual UAT — 2 browser-only scenarios outstanding (`04-HUMAN-UAT.md`).
- 6 Phase-2 code-review polish items + diet edit-form density desync (`2026-06-02-diet-edit-form-density-desync…`).
- Meal-note redaction granularity — product question (per-entry free-text notes vs aggregate kcal line).
- Surface block-action errors (approve/discard/edit) in chat-page — currently console-only.
- 2 diagnosed debug sessions (dev-seed) — fixed in code, sessions not formally closed.

**Technical Debt Incurred:**

- Coverage thresholds surfaced pre-existing per-file misses on several services (chat/diet/readings/weight/fitness-context) — not regressions; candidates for a future coverage pass.
